## PWA Support

The landing page now ships as a Progressive Web App:

- Manifest metadata lives in `public/manifest.json` and points to the install icons in `public/icons/`.
- A lightweight service worker (`public/sw.js`) precaches the shell and caches `/tokens/*` responses with a network-first strategy so the feed stays available offline.
- `PwaInitializer` registers the worker from the client bundle and asks it to skip waiting once installed.
- The layout injects the `<link rel="manifest">`/ `<meta name="theme-color">` tags so browsers treat the experience as installable.

Run `npm run dev` and open `http://localhost:3000` (or the built output) to try the installable experience.
